## What's in the portfolio?

### Featured projects

**[Orbit Defender](projects/orbit-defender.html) — JavaScript, HTML5 Canvas, CSS**

A browser-based space shooter I built with enemy waves, boss battles, collectible upgrades, difficulty levels, and a high-score system. Building it was a chance to practice game loops, collision detection, user input, and debugging. **[Play the game](projects/orbit-defender.html).**

**[Hamilton Highlights](projects/hamilton-highlights.html) — JavaScript, Bootstrap, Google Maps API**

An interactive guide for discovering places around Hamilton. It explores location search, maps, filtering, and directions. The portfolio includes a case study and a safe source-code sample rather than a fully hosted demo, because the original application uses a Google Maps API key.

**[Pawffee Break](projects/pawffee-break.html) — WordPress, PHP, CSS, MySQL**

A pet-café website concept with pages for pet adoption, visiting information, a gallery, blog, and contact details. It helped me explore website structure, presentation, and WordPress customization. A case study is included; the original WordPress site needs a server and database to run.

### Other work

- **FIFA Stadium Explorer:** A mobile stadium-discovery project built with React Native and Expo, exploring maps, search, and saved locations.
- **Doctor Who Database Application:** A C# Windows Forms coursework project working with related records and SQL data.
- **Counselling Appointment System:** A systems-analysis and design project covering requirements, appointment workflows, and data-flow diagrams. This is a design project, not a deployed application.
- **Git Collaboration Workflow:** Coursework using branches, commits, pull requests, and teamwork on a shared GitHub repository.

## About this website

The portfolio itself is a **static website built with HTML, CSS, and JavaScript** and designed for publishing with **GitHub Pages**. It includes a mobile-friendly layout, project filters, screenshots, a printable résumé, and a PDF résumé download. No build tools or packages are required to view it.

To run it locally, download or clone this repository and open `index.html` in a browser. To browse the code, start with:

- `index.html` — main portfolio page
- `styles.css` and `script.js` — styling and interactions
- `projects/` — the playable Orbit Defender game and project case studies
- `images/` — project screenshots
- `resume.html` and `Francis_Iguwa_Resume.pdf` — résumé versions
