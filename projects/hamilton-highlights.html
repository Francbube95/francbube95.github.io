WEB APP / PROJECT CASE STUDY

Hamilton Highlights

An interactive guide to places worth exploring in Hamilton, Ontario, designed around a map and practical visitor tools.

JavaScriptGoogle Maps APIBootstrapGeolocation

The problem

Help visitors browse local attractions and get directions without jumping between multiple websites.

My approach

I built a responsive two-column interface, configured categories of attractions, and connected location controls to Google Maps services. I wrote the marker filtering, geolocation, address search and directions logic in JavaScript.

Key features

  • Map pins for landmarks, museums, parks and food spots
  • Filters that update both the map and destination selection
  • Optional browser geolocation, with permission/error handling
  • Add a new place by address through geocoding
  • Driving directions to a selected destination

What I learned

Integrating an external mapping service, synchronizing filters with markers, interpreting browser permissions and validating inputs. The project also emphasized keeping API credentials restricted.

Source and deployment

The Google Maps application requires a valid, restricted API key and enabled Google services. The provided source excerpt removes the original hard-coded key. No live demo is claimed on GitHub Pages.
