Pawffee Break

A WordPress website concept for a welcoming pet café, combining visitor information with content about adoptable pets.

WordPressPHPMySQLChild Theme

The problem

Make it easy for a visitor to discover the café, learn about the adoption theme and find useful information before a visit.

My approach

I assembled the site in WordPress and structured navigation and content for a homepage, adoption information, visiting hours, gallery, blog, contact and jobs pages. The archive includes a Twenty Twenty-Five child theme and project media.

Key features

  • Clear homepage with a café-themed hero section
  • Adopt a Pet and pet-related content sections
  • Hours & Visit, Gallery and Blog navigation
  • Contact and Jobs pages
  • WordPress child-theme configuration and site content

What I learned

Working with a content management system, thinking about site navigation, tailoring a WordPress theme and organizing a multi-page experience for visitors.

Source and deployment

This project runs on WordPress with PHP and MySQL, not on a static GitHub Pages server. The download contains only a small child-theme excerpt; it intentionally excludes database exports, WordPress configuration, bundled plugins and credentials.
